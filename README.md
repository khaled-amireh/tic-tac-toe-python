# Tic Tac Toe (Python)

A simple console-based Tic Tac Toe game built with Python.

## Features

* Play against the computer
* Random computer moves
* Input validation
* Win / Lose / Draw detection

## How to Run

1. Open the project
2. Run `tic_tac_toe.py`
3. Enter a number from 1 to 9 to play

## Game Rules

* You are **O**
* The computer is **X**
* First to get 3 in a row wins
